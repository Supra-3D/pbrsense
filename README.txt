PBRSense project page

This package contains the current static page, video, title animation, comparison
matrices, used images, local fonts, and font licenses. No model or Node build is
required. Keep the directory structure intact.

Preview with Python 3 from this directory:
  python3 -m http.server 8000
Then open http://localhost:8000/ in a browser.

Use HTTP serving rather than double-clicking index.html: the comparison matrices
load JSON and JavaScript modules. For static hosting, upload this directory's
contents to your website root or project directory.
